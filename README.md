# Интерактивная 3D Книга (Flip Book)

Этот проект представляет собой интерактивную веб-страницу, имитирующую 3D-перелистывание страниц книги с помощью HTML, CSS и JavaScript.

## Стек технологий

*   **HTML5**: Структура книги и её страниц.
*   **CSS3**: Стилизация, 3D-трансформации для эффекта перелистывания, анимации и общий внешний вид.
*   **JavaScript (ES6+)**: Логика перелистывания страниц, управление состоянием книги и обработка пользовательских событий.

## Особенности

*   **Реалистичное 3D-перелистывание**: Эффект переворота страниц достигается с помощью CSS `transform-style: preserve-3d;` и `rotateY()`.
*   **Динамическое управление страницами**: JavaScript отслеживает текущую страницу и применяет соответствующие классы для визуализации перелистывания.
*   **Навигационные кнопки**: Удобные кнопки "Вперед" и "Назад" для управления чтением.
*   **Настройка Z-index**: Правильное наложение страниц для корректного отображения 3D-эффекта.
*   **Адаптивный дизайн**: Книга занимает большую часть экрана, подстраиваясь под разные размеры окна браузера.
*   **Привлекательный дизайн**:
    *   Темный фон.
    *   Шрифт 'Lato', serif для книжного вида.
    *   Цвета страниц имитируют старую бумагу с текстурами.
    *   Обложка и задняя обложка в винтажном бордовом стиле.
    *   Кнопки управления выполнены в стиле старой кожи.

## Структура проекта

*   `index.html`: Основной файл, содержащий структуру HTML книги.
*   `styles.css`: Файл стилей для оформления и 3D-эффектов.
*   `script.js`: Файл JavaScript, реализующий логику перелистывания страниц.

## Как использовать

1.  Клонируйте репозиторий: `git clone [ссылка_на_ваш_репозиторий]`
2.  Откройте файл `index.html` в вашем веб-браузере.
3.  Используйте кнопки `<` и `>` для перелистывания страниц.
